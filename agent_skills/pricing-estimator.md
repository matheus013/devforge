# PRICING-ESTIMATOR

Objective: estimate project setup and recurring cost.

Inputs: project type, complexity, integrations, agent run history, risk level.

Process: choose baseline price, adjust for complexity and maintenance needs, return transparent assumptions.

Output: setup price, monthly price, currency, assumptions.

Rules: keep estimates deterministic in the MVP.

Common errors: hiding assumptions, ignoring high-risk imports.

Quality criteria: pricing can be reviewed and revised by staff.
