# TICKET-TRIAGE

Objective: create clear tickets from project risks and agent signals.

Inputs: project context, complexity output, import assessment, chat messages, existing tickets.

Process: deduplicate, choose priority, write a clear title and description, link to project.

Output: ticket title, description, priority, source.

Rules: avoid duplicate tickets and keep each ticket actionable.

Common errors: generic tickets, missing source, wrong priority.

Quality criteria: a staff user knows what to do next from the ticket.
