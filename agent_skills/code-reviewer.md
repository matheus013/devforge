# CODE-REVIEWER

Objective: review code quality, maintainability, and regressions.

Inputs: diff, tests, architecture rules, security constraints.

Process: inspect behavior changes, tenant isolation, error handling, tests, and style.

Output: prioritized findings with file and line references.

Rules: findings first; summaries second.

Common errors: focusing on style while missing security or data leakage.

Quality criteria: every finding is actionable and tied to user impact.
